# Archive

Historical planning notes, session summaries, release notes and superseded
guides, kept for reference only. They are not maintained and are **not
accurate** for the current release. Many describe APIs that no longer exist or
never shipped. Several make claims the project does not stand behind:
GPU or ML speedups, regulatory compliance (HIPAA, FIPS and similar),
constant-time behaviour, undetectability, and production readiness. Disregard
them.

Current documentation: [the docs index](../README.md).
